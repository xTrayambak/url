# Contributors' Guide
This is a short document on do(s) and don't(s) for contributing to [nim-url](https://github.com/xTrayambak/url).

## Merge Requests/Pull Requests
If you make a MR/PR, make sure to have a proper title and description as to what the request changes. It makes reviewing the code a bit easier.

### AI Policy
Using AI models to generate code is not strictly forbidden, but you must take full responsibility for anything and everything you contribute that is written by an AI model. (i.e, "I generated it using AI, I didn't know what it does" is not a valid excuse)

I frankly do not care about what tools you use to write code, be it just a simple LSP+text editor like me, or some new fancy, shiny "AI IDE" with all the bells and whistles. I just want all MRs to be produced in a way that the author understands what is inside of one.

## Issues
Issues should be descriptive, and contain a minimal reproduction sample when appropriate.
